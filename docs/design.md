# Intact — Design System & Visual Identity

## 1. Aesthetic Direction
**Cool Archival Inspection Record** — A calm, credible, modern technical survey and tenancy condition documentation tool.

## 2. Palette & Tokens
- **Background (`page`)**: `#F4F5F7`
- **Surface**: `#FFFFFF`
- **Primary Text (`ink-900`)**: `#1C1E21`
- **Secondary Text (`ink-600`)**: `#4A4E54`
- **Muted Metadata (`ink-500`)**: `#6B7078`
- **Default Border (`ink-200`)**: `#D1D5DB`
- **Strong Border (`ink-400`)**: `#9CA3AF`
- **Primary Accent (`accent`)**: `#0B3D4A` (Deep Teal — only brand accent)
- **Accent Hover (`accent-hover`)**: `#072E38`
- **Accent Tint (`accent-tint`)**: `#E0F0F3`

### Semantic Classification & Decision Tokens
- **DAMAGE**: `#A63D3D` (bg: `#FDF2F2`, border: `#F8D7D7`) — Solid muted red box on departure photo.
- **NORMAL WEAR**: `#8A6A1A` (bg: `#FEF9EC`, border: `#F6E3B4`) — Solid ochre box. Always written as "NORMAL WEAR", never shortened to "WEAR".
- **UNCLEAR**: `#5A5F66` (bg: `#F4F5F7`, border: `#D1D5DB`) — 2px dashed grey box.
- **ACCEPTED**: `#2A5C4A` (bg: `#EDF7F3`, border: `#C3E6D9`)
- **DISPUTED**: `#5C3D6B` (bg: `#F7F0F9`, border: `#E4CEE9`)

## 3. Typography
- **UI / Headings / Body**: `IBM Plex Sans`
- **Timestamps / SHA-256 Hashes / IDs / Metadata / Confidence**: `IBM Plex Mono`

## 4. Design Guidelines
- No gradients, glow, or glassmorphism.
- Thin 1px borders for structure and division.
- Small restrained corner radii (`2px` - `4px`).
- Flat, tactile, document-like presentation.
